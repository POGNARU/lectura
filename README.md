# 낭독 노트 · lectura

> 소리 내어 읽기 위해 준비한 것들

**→ [pognaru.com/lectura](https://pognaru.com/lectura/)**

포근나루(POGNARU STUDIO)의 햇살이 **원서를 낭독하기 전에 준비한 노트**를 모으는 아카이브입니다.
낱말·발음·억양·해석 — 한 대목을 소리 내어 읽기 위해 필요한 것을 회차별로 쌓아갑니다.

## 구조 — 세 층

```
index.html                       책장 — 읽고 있는 책 카드
  └ books/<책>.html              그 책의 회차 목록 (최신이 맨 위)
      └ entries/<책>-YYMMDD.html 그날의 낭독 노트 (YYMMDD = 낭독하는 날)
```

책이 늘어나면 `books/`에 한 장, `index.html`에 카드 한 개를 더한다. **책마다 노트를 따로 둔다** — 한 페이지에 여러 책을 섞지 않는다.

## 새 회차 더하는 법

1. `entries/<책>-YYMMDD.html` 를 만든다 — 기존 회차를 복사해 쓰는 게 빠르다.
   **날짜는 준비한 날이 아니라 낭독하는 날이다** (2026-08-19 다현씨 확정). 목록에서 “언제 읽는 대목인가”가 보여야 하기 때문이다
2. `books/<책>.html` 의 `⬇⬇ 새 회차는 이 줄 바로 아래에 추가 ⬇⬇` 주석 **바로 아래**에 카드 한 줄을 넣는다
3. `index.html` 책 카드의 회차 수 칩을 고친다

> **최신이 언제나 맨 위다** (2026-08-19 다현씨 확정). 회차 목록도, 책장도. 위에서부터 읽어 내려가면 최근 것이 먼저 온다.

## 노트 한 장의 뼈대

회차마다 담는 것이 정해져 있다. 순서를 지키면 매번 같은 자리에서 같은 것을 찾을 수 있다.

1. **범위·분량·성격** — 맨 위 상자(`.facts`)
2. **낱말** — 열쇳말 하나를 앞세우고, 동사 / 명사·형용사 / 관용구 표
3. **발음** — 규칙별 목록. 왜 그런지가 필요하면 `.box`로 따로 뺀다
4. **범위 전체** — `.tri` 블록에 원문 / 한글 발음 / 해석 세 줄 (대목이 길면 생략 가능)
5. **낭독 설계** — 화자·억양·문장부호·착지
6. **준비 순서** — 15분짜리 5단계

## 공개 범위

> **검색에 걸리지 않게 막아두었다.** `robots.txt`와 전 페이지 `<meta name="robots" content="noindex, nofollow">`.
> **새 노트를 만들 때 이 메타 태그를 빠뜨리지 말 것.**
>
> **`robots.txt`는 이 폴더에 있어도 크롤러가 읽지 않는다.** 검색엔진은 도메인 뿌리의 `pognaru.com/robots.txt`만 본다.
> 그러니 실제로 막아주는 것은 **전 페이지의 noindex 메타 태그 하나뿐**이다. 절대 빠뜨리지 말 것.
> (뿌리 `robots.txt`에 `Disallow: /lectura/`를 적는 방법도 있지만, 그러면 공개 파일에 감출 경로를 광고하는 셈이라 하지 않는다.)
>
> 이유는 저작권이다. 노트에 원문 문장이 그대로 실린다. 준비 노트라는 성격상 인용 범위를 넘지 않지만, 검색으로 유입되어 원문 열람용으로 쓰이면 곤란하다. pognaru.com이나 다른 채널에 링크를 걸지 않는다. 다만 **함께 공부하는 분들께 주소를 직접 건네는 것은 괜찮다**(2026-08-19 다현씨 확정) — 검색으로 흘러드는 것만 막으면 된다.
